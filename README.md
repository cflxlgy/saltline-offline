# Saltline 离线版

个人离线存档。原游戏：[Saltline on Claude](https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp)。原作者权利和代码内已有许可声明保留。

## 下载与运行

1. 点击本仓库的 **Code → Download ZIP**，下载并解压。
2. 用 Edge 或 Chrome 打开 `index.html`，或在 Windows 上双击 `开始游戏.cmd`。
3. 等待初始化，点击 **Deploy**。画面卡顿时在 **Settings** 中降低画质。

运行时不需要访问 Claude、登录账号或使用 VPN。游戏场景和声音在浏览器内生成；已移除 Claude 页面框架与 Google 在线字体，改用系统备用字体。

操作：WASD 移动，鼠标控制视角，左键射击，右键瞄准，R 换弹，按住 E 切断中继，空格跳跃，Shift 冲刺，C/Ctrl 蹲下，F 近战，Esc/P 暂停。

更多说明见 [使用说明.md](使用说明.md)。已通过脚本语法与压缩包完整性检查；尚未完成本地实机试玩。需要支持 WebGL 的现代浏览器和显卡。
